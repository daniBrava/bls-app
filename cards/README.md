# מאגר כרטיסיות BLS

מקור הנתונים לאפליקציה הוא `cards/cards.he-IL.json` (JSON בקידוד UTF-8). אפשר לטעון אותו בזמן הבנייה או לצרף אותו כמשאב מקומי. אין צורך להעתיק את תוכן הכרטיסיות לפרומפט.

## שילוב באפליקציה

- קראו את `cards` לפי הסדר בקובץ והשתמשו ב-`id` כמזהה קבוע. הציגו את `title` ואת `group` בניווט.
- הציגו את `sections` לפי סדר המערך, ואת `items` לפי הסדר בסעיף. המספור הקליני מכוון: 1, 2, 4, 3, 5, 6. לכרטיסיות נוהל יש שלושה סעיפים.
- הציגו מימין לשמאל, לפי `direction`. השדה `sources` מכיל קישור וסימון עמוד או פרק כשזמין. בשלוש הכרטיסיות שהועברו מהמשתמש לא נמסרו אסמכתאות לכרטיסייה עצמה.
- `editorial_status` מתעד אם הכרטיסייה אושרה בפרויקט או מחכה להכרעה. `operational_status` מתעד אם התוכן אומת לשימוש מבצעי. השדה `review_needed` מפרט מה דורש בדיקה בכל כרטיסייה.
- במצב עריכה או סקירה אפשר להציג כרטיסיות עם `review_required` בצירוף הערת הבדיקה. במצב מבצעי הציגו כרטיסייה כמאומתת רק לאחר שהגורם המוסמך אישר אותה והסטטוס עודכן. בקובץ הנוכחי כל הכרטיסיות ממתינות לאימות מבצעי.
- מזהי הכרטיסיות לקישורים פנימיים כוללים `newborn-resuscitation`, `cpr-aed`, `major-trauma` ו-`anaphylaxis`. השאירו אותם קבועים גם אם הכותרות ישתנו.

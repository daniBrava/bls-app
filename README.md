# כרטיסיות BLS

אפליקציית עזר לחובשי רפואת חירום BLS: כרטיסיות שזמינות גם בלי אינטרנט, ותיעוד אירוע שמפיק טיוטת דוח רפואי. האפליקציה בעברית ומותאמת לאייפון.

- `cards/cards.he-IL.json`: מאגר הכרטיסיות. ההנחיות לשימוש בו נמצאות ב-`cards/README.md`.
- `app/`: קוד האפליקציה. הסבר מלא נמצא ב-`app/README.md`.
- `cases/cases.he-IL.json`: רשימת המקרים. הקובץ לא חובה וייתווסף בהמשך.

## פרסום

כל דחיפה לענף `main` מריצה את הבדיקות, בונה את האפליקציה ומפרסמת אותה ב-GitHub Pages. ההגדרה נמצאת ב-`.github/workflows/pages.yml`. בטלפון מופיעה אחרי זה ההודעה "גרסה חדשה זמינה".

אין צורך להריץ את הבנייה ידנית. הבנייה המקומית מיועדת לבדיקה בלבד:
```
python3 app/build.py
python3 -m http.server 8000 -d app/dist
```

## פרטיות

פרטי מטופלים לא נכנסים למאגר ולא לאתר. הם נשמרים רק במכשיר של החובש.
